# bob_sessions

IBM Bob task session screenshots. One set per team member.

Required for judging eligibility. Capture these as you work, not afterwards.

How:
1. In the Bob IDE chat interface, open Tasks.
2. Use the All filter if your tasks span more than one workspace.
3. Select the task header to reveal the task session consumption summary,
   showing context length, task id, workspace, tokens, cache and API cost.
4. Screenshot it.
5. Save here as firstname_task_01.png and commit.
